# data/

Raw and cleaned source datasets that feed the financial model and analytical deliverables — the single source of truth for any numbers that flow downstream. [`skf-financial-summary-2021-2025.md`](skf-financial-summary-2021-2025.md) consolidates AB SKF's five-year financial data (2021–2025) extracted from audited Annual Reports and Alternative Performance Measures (APM) disclosures, organised into Profitability, Balance Sheet & Leverage, Cash Flow & Capital Allocation, Per-Share & Market Data, and Items Affecting Comparability (IAC) Detail sections. This file is the bridge between AB SKF's raw filings and the structured FY2024/FY2025 inputs landed in the Stage 3 Excel model. Files here are intentionally Markdown (not CSV) — the analytical narrative around each value matters as much as the value itself. Naming convention: `{company-slug}-{kind}-{period}.md`.
