# models/builds/

Working financial models populated with company-specific data for each project stage. The Stage 3 deliverable [`2026-05-19-dang-skf-financials.xlsx`](2026-05-19-dang-skf-financials.xlsx) is the canonical numerical source for the FY2025 ratio analysis — six tabs (Cover, Balance Sheet, Income Statement, Cash Flow Statement, Ratios, Notes) populated from AB SKF's Annual Report 2025 with line-by-line source verification. The model implements the named-range conventions specified in [`docs/specs/2026-05-24-dang-skf-spec.md`](../../docs/specs/2026-05-24-dang-skf-spec.md) (e.g., `BAL_*_curr`, `BAL_*_prior`, `INC_*`, `RATIO_*`, `startYear_*`, `currentYear_*`, `avg_*`) so that ratio formulas read as auditable algebra rather than cell references. Validation rules V1–V9 from the spec are verified to pass; the Stage 5 manual recomputation at [`analysis/validation/2026-05-27-dang-skf-stage5-verification.md`](../../analysis/validation/2026-05-27-dang-skf-stage5-verification.md) cross-checks 9 ratios across all 6 categories against this workbook. Naming convention: `YYYY-MM-DD-dang-{company}-{kind}.xlsx`.
