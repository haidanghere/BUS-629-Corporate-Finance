# deliverables/

Final submission-ready artefacts for each project stage — the files that get handed in for grading. Stage 5 contributes four files: [`2026-05-27-dang-skf-llm-raw.md`](2026-05-27-dang-skf-llm-raw.md) (unedited LLM execution of the Stage 4 spec), [`2026-05-27-dang-skf-final-analysis.md`](2026-05-27-dang-skf-final-analysis.md) (the polished analysis with corrections from the verification table, author voice, R1–R5 strategic recommendations in `[Data]`/`[LLM]` attribution format, and a Reconciliation-to-AR note documenting Stage 3 spec conventions vs. AR 2025 presentation), [`2026-05-27-dang-skf-spec-retrospective.md`](2026-05-27-dang-skf-spec-retrospective.md) (the spec evaluation), and the extra-credit [`2026-05-27-dang-skf-peer-benchmark.md`](2026-05-27-dang-skf-peer-benchmark.md) (peer benchmarking of SKF against the exact competitor universe identified in SKF's own Annual Report 2025: Schaeffler, NSK, NTN, JTEKT, and Timken — across operational profile, profitability, leverage, liquidity, efficiency, and valuation). [`prompt-log.md`](prompt-log.md) is the cross-stage audit trail of every AI-assisted prompt and decision, organised chronologically from Stage 2 through Stage 5 (intentionally not date-prefixed so it remains the project's running ledger). Naming convention for stage deliverables: `YYYY-MM-DD-dang-{company}-{kind}.md`. New deliverables go here; intermediate or working products belong in `analysis/` or `docs/`.
