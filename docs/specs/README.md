# docs/specs/

Technical specifications for each modelled deliverable — defines inputs, named ranges, formulas, validation rules, and expected outputs before work begins. The Stage 4 deliverable [`2026-05-24-dang-skf-spec.md`](2026-05-24-dang-skf-spec.md) is the canonical reference for the FY2025 ratio model: 12 sections covering Scope, Model Architecture, Data Inputs, Named-Range Conventions, Derived Inputs, 30 Ratio Definitions across 6 categories, Validation V1–V9, Analysis Requirements, Du Pont Decomposition, Strategic Recommendation Framework, Output Format, and a §12 Sensitivity Extension. The spec was iterated twice (v1.0 → v2.0) with the explicit goal that a cold-context Stage 5 LLM could reconstruct the analysis from spec text alone; the iteration evidence lives at [`analysis/validation/2026-05-24-dang-skf-stage4-iteration.md`](../../analysis/validation/2026-05-24-dang-skf-stage4-iteration.md) and the spec retrospective (what worked, what didn't) at [`deliverables/2026-05-27-dang-skf-spec-retrospective.md`](../../deliverables/2026-05-27-dang-skf-spec-retrospective.md). Naming convention: `YYYY-MM-DD-dang-{company}-spec.md`.
