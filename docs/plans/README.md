# docs/plans/

Reserved space for stage-by-stage written plans and task breakdowns. Intentionally lean — most planning across this project happens in the [`prompt-log.md`](../../deliverables/prompt-log.md) (which records every analytical decision the AI prompts surfaced) and in git commit messages, rather than in static planning documents. If a multi-week workstream were to require a written plan, it would land here with naming `YYYY-MM-DD-dang-{slug}-plan.md`. Currently empty by design.
